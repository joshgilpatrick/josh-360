# Inventory

The inventory of the work laptop and of Session Atlas and action-triage, with a verdict per item (JP-96, JP-97).

- `laptop.md`: every job, hook, plugin, memory mechanism, data store, agent definition and skill on the work laptop, with a verdict of keep, migrate, build new or dismantle, the dismantling plan and the questions for JP-106 (JP-96).
- `starting-figures.md`: the numbers later change is measured against, each with its date range and command (JP-96).
- `features.md`: every feature of action-triage and Session Atlas with a verdict, its carrier ticket, the overlaps between the two apps, their local data stores, and the questions for the phase 1 sitting (JP-97).

`scripts/check.py` checks every row of all three. `scripts/laptop_inventory.py` refreshes the laptop half from the laptop, read-only.
