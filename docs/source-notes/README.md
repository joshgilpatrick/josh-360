## What these are

Josh's own notes, copied here unchanged on 16 November 2026 so that agents working the Josh 360 tickets can read them. They are inputs, not rules. Where a note and `docs/vision-and-roadmap.md` disagree, the vision document wins.

## The development pipeline draft

The 22-step pipeline Josh drafted as a Paseo playbook. The development graph is built new from it.

- `playbook-workflow-handoff.md`: how the playbook is meant to run.
- `jira-ticket-pipeline.yaml`: the pipeline itself.
- `jira-ticket-pipeline-defaults-main.yaml`: its default settings.
- `jira-ticket-pipeline-roles-and-scripts.md`: the roles and the gate scripts.
- `jira-pipeline-swimlane.html`: a picture of the pipeline. Open it in a browser.
