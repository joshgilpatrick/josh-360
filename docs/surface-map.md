## What this is

Every surface Josh works through for his developer experience (DevEx), and where each one's configuration lives. It was written on 16 November 2026 from a cloud session (JP-98), by reading the repositories claude-harness, action-triage, claude-360 and macbook-automations, the josh-360 vision and Jira. Nothing on the laptop itself was opened, so each row names its source, and a row marked "not checked" needs a look on the laptop (JP-105 connects it).

`~` is Josh's home folder on the work laptop. Paths under `~/.claude` are the claude-harness repository. The inventory (JP-96, JP-97) gives each item a verdict; this map only says where things are.

## Shared configuration every agent surface reads

| What | Where |
| --- | --- |
| Global rules | `~/.claude/AGENTS.md` |
| Skills | `~/.claude/skills/` (canonical), linked into the other tools |
| Subagents | `~/.claude/agents/` |
| Plugins | `enabledPlugins` in `~/.claude/settings.json`; installed copies in `~/.claude/plugins/` |
| Per-session state | `~/.claude/session-state/<session id>/STATE.md`, `~/.claude/session-focus/` |
| Per-project memory | `~/.claude/projects/<project>/memory/` |
| Files for Josh to review | `~/Development/active/.artifacts/<repo>/` |
| Ticket conventions, system registry, priorities | `conventions/` in josh-360 |
