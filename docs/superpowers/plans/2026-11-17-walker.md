## Goal and constraints

Build JP-114: one script that says the next step of a graph, records every step in the ledger, parks a run on a question for Josh and resumes it, ends a loop at a human, refuses a graph the checker rejects, saves the spec and evidence outside the repository, and moves the Jira status through a script. Design: `docs/superpowers/specs/2026-11-17-walker-design.md`. Rules it follows: `graphs/CONVENTION.md` ("How a graph runs", "The run cap").

Constraints: laptop Python 3.9 and the standard library only; made-up data only; a gate script is a subprocess; the walker starts no sessions and decides no start (JP-117); no patient data in the ledger, GitHub or Jira.

- [x] 1. `graphs/tools/compile_graphs.py`: the JSON copy of each graph, with source hashes, refused when the checker rejects the graph; `graphs/compiled/` holds the three copies; `scripts/check.py` fails on a stale or missing copy.

- [x] 7. Documents: `graphs/CONVENTION.md`, `graphs/README.md`, `AGENTS.md`, `docs/decisions.md`.

## How it is proved

`python3 scripts/check.py` runs the tests and the compile check. The proof page shows a made-up run through the sample graph: the next step following each outcome, a parked run answered from another process, a loop ending at a human, and a rejected graph not run.
